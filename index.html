Relatório técnico

Importar inventário

Aceita XLSX/CSV no navegador. As colunas recomendadas são: ID, Tipo, Local, Pavimento, Status, Última inspeção, Próxima ação, Prioridade, Observações.

Regras de reconciliação

  • ID existente → atualizar registro.
  • ID novo → criar registro.
  • Conflito de evidência → sinalizar divergência.
  • Dados ausentes → gerar pendência.
  • Histórico anterior não é apagado automaticamente.
