# Arquitetura de produção

## Domínios
1. Tenant/organização
2. Condomínio
3. Edificação / torre / bloco
4. Pavimento / ambiente
5. Equipamento
6. Inspeção
7. Evidência
8. Não conformidade
9. Ordem de serviço
10. Ensaio
11. Substituição
12. Requisito normativo
13. Relatório
14. Auditoria
15. Usuário / perfil

## Modelo de rastreabilidade
LOCALIZAÇÃO → EQUIPAMENTO → FOTO/DOCUMENTO → INSPEÇÃO → EVIDÊNCIA → NÃO CONFORMIDADE → AÇÃO → ENSAIO → MANUTENÇÃO/SUBSTITUIÇÃO → HISTÓRICO → RELATÓRIO

## Requisito normativo
Cada requisito deve possuir:
- fonte
- norma/documento
- versão
- vigência
- jurisdição
- item
- texto do requisito
- evidência necessária
- resultado
- responsável pela validação

Nunca gerar número ou obrigação normativa sem fonte verificável.
